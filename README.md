# Sales-Performance-Analysis-Dashboard
Interactive Sales Performance Dashboard built with Excel to track revenue, order volume, and regional growth across multiple countries and product categories.

Sales Performance Analysis Dashboard
📌 Project Overview
This dashboard provides a comprehensive analysis of sales transactions, designed to help business stakeholders monitor performance and identify growth opportunities across different markets. The analysis covers key metrics like total revenue, order count, and regional sales distribution.

📊 Key Metrics (KPIs)
The dashboard tracks three primary business indicators:

Total Sales Revenue: $1,034,734.

Total Order Volume: 214 orders.

Average Sales Value: $4,835.21 per order.

🛠️ Features & Visualizations
Regional Sales Distribution: A pie chart representing sales across East, North, South, and West regions.

Top Performing Countries: A bar chart comparing revenue generated from countries including the US, UK, Germany, France, and Canada.

Product Category Analysis: A breakdown of sales between 'Fruit' and 'Vegetables'.

Sales Trends over Time: A line chart visualizing monthly sales fluctuations throughout the year.

Advanced Filtering: Interactive slicers for Year, Category, Country, Quarter, and Region to allow for granular data exploration.

📂 Dataset Structure
The underlying data includes detailed transactional records:

Order ID & Date: For chronological tracking.

Product & Category: Categorization of sold items (e.g., Apples, Carrots, Bananas).

Geographic Data: Country and Region details.

Financial Data: Individual transaction amounts.

💻 Technical Skills Applied
Data Cleaning: Preparing raw sales records for analysis.

Pivot Tables: Summarizing large datasets into meaningful business reports.

Dashboard Design: Creating a user-friendly interface with interactive elements like Slicers and Timeline.
